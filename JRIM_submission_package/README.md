# JRIM Submission Package

Materials for preparing `JRIM_formatted_manuscript.docx` for submission to the
*Journal of Research in Interactive Marketing* (Emerald).

| File | Purpose |
|---|---|
| `01_JRIM_compliance_checklist.md` | Point-by-point audit against Emerald/JRIM author guidelines, plus top-tier improvement recommendations |
| `02_submission_statements.md` | Paste-ready statements: ethics & consent, funding, conflict of interest, data availability, AI-use disclosure, cross-sectional caveat, H5 results wording, and the five updated 2025 references in Emerald Harvard format |

## Status

The manuscript files (`JRIM_formatted_manuscript.docx`,
`manuscript_IJEMR_tables.docx`) live on the author's local machine and were
not available in this repository, so checklist items marked **⚠ verify** must
be confirmed against the documents directly. To enable an automated
line-by-line compliance pass, add the two .docx files to this repository (or
re-authorize the Google Drive connection) and re-run the review.

## Key risks identified

1. **Interactivity framing** — JRIM desk-rejects papers that don't engage
   interactive marketing explicitly (see 2025 JRIM editorial,
   doi: 10.1108/JRIM-03-2025-0135).
2. **Tables file carries another journal's name** (`IJEMR`) — scrub and rename
   before submission.
3. **Ethics statement placeholders** — committee name, approval number and
   date must be completed (blinded variant goes in the anonymised file).
4. **H5 figures (21.4 / 13.1 pp)** — must be verified against final PLS output.
